# Управление проектом

Этот раздел фиксирует учебную оценку работ по проекту «Разработка веб-приложения по продаже программного обеспечения». Он описывает фактически выполненные направления, а не является производственным планом команды.

## WBS

1. Анализ требований и предметной области.
2. Проектирование PCMEF-архитектуры.
3. Проектирование PostgreSQL-схемы и миграций Flyway.
4. Реализация backend и доменной модели.
5. Реализация REST API и DTO.
6. Реализация Web UI на Thymeleaf и JavaScript.
7. Настройка JWT-аутентификации и разграничения ролей.
8. Unit- и MockMvc-тестирование.
9. Минимальный рефакторинг, Checkstyle и анализ покрытия.
10. Подготовка WAR, Docker Compose и Tomcat-развёртывания.
11. Подготовка технической документации.
12. Финальная сборка и smoke-проверка.

## Gantt

Учебный календарный план приведён в [gantt.puml](gantt.puml). Даты иллюстративны: они показывают порядок и частичное перекрытие работ, а не фактический журнал трудозатрат.

## COCOMO

Подсчёт выполнен для исходников `src/main/java`, без `target/` и генерируемых файлов:

- Java-файлов: 71;
- непустых строк Java: 1 451;
- размер: 1.451 KLOC.

Для учебного проекта выбран Basic COCOMO, режим Organic:

```text
Effort = 2.4 × KLOC^1.05 = 3.55 чел.-месяца
Development Time = 2.5 × Effort^0.38 = 4.05 месяца
Average Staff = Effort / Development Time = 0.88 человека
```

Это ориентировочная модельная оценка. Она не заменяет фактический учёт времени и не учитывает повторное использование Spring Boot, библиотек и инструментов сборки.
