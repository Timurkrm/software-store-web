# Руководство пользователя

## Открытие приложения

**Цель:** перейти к витрине магазина.  
**Действия:** после запуска откройте `http://localhost:8080/`; из меню выберите «Каталог».  
**Результат:** доступна главная страница и публичный каталог. Вход для просмотра каталога не требуется.

## Регистрация

**Цель:** создать учётную запись пользователя.  
**Действия:** откройте `/auth`, выберите регистрацию, укажите корректный e-mail и пароль не короче шести символов, затем отправьте форму.  
**Результат:** сервер создаёт пользователя с ролью `USER`; при повторном e-mail будет показана ошибка.

## Вход

**Цель:** получить доступ к корзине, заказам и лицензиям.  
**Действия:** на `/auth` укажите зарегистрированные e-mail и пароль.  
**Результат:** JWT сохраняется в браузере, а пользователь переходит к каталогу. Сеанс используется для защищённых API-запросов.

## Каталог, поиск и карточка продукта

**Цель:** найти программный продукт и узнать его свойства.  
**Действия:** откройте `/catalog`, используйте поле поиска; выберите карточку найденного продукта.  
**Результат:** каталог загружается из публичного API; на `/product/{id}` отображаются название, разработчик, версия, цена, категория и описание доступного продукта.

## Добавление в корзину

**Цель:** подготовить ПО к заказу.  
**Действия:** войдите, откройте карточку продукта и нажмите добавление в корзину.  
**Результат:** товар появляется в серверной корзине пользователя. Без входа приложение направляет на `/auth`.

## Изменение и удаление позиций

**Цель:** скорректировать состав покупки.  
**Действия:** откройте `/cart`, измените количество позиции в диапазоне 1–99 либо удалите позицию. При необходимости очистите корзину.  
**Результат:** сервер пересчитывает сумму корзины; удалённая позиция больше не участвует в заказе.

## Оформление заказа

**Цель:** создать заказ из текущей корзины.  
**Действия:** в корзине нажмите оформление заказа.  
**Результат:** создаётся заказ со статусом `PENDING_PAYMENT`; цена каждой позиции фиксируется на момент создания заказа, а корзина очищается.

## Заказы и оплата

**Цель:** просмотреть историю и оплатить ожидающий оплаты заказ.  
**Действия:** откройте `/orders`, выберите заказ со статусом `PENDING_PAYMENT` и нажмите оплату.  
**Результат:** demo-payment переводит заказ в `COMPLETED`, создаёт запись оплаты и выдаёт лицензии. Повторно оплачивать такой заказ нельзя.

## Лицензии

**Цель:** получить ключи приобретённого ПО.  
**Действия:** после успешной оплаты откройте `/licenses` из профиля или меню.  
**Результат:** показаны лицензии текущего пользователя, связанные с оплаченными товарами и заказом.

## Выход

**Цель:** завершить работу на устройстве.  
**Действия:** в меню пользователя нажмите «Выйти».  
**Результат:** JWT и сведения о пользователе удаляются из `localStorage`; защищённые страницы снова требуют входа.
