# OpenAPI and Swagger UI

После запуска приложения Swagger UI доступен по адресу:

```text
http://localhost:8080/swagger-ui/index.html
```

Спецификация v1 доступна как группа `v1`; её JSON можно получить по `/v3/api-docs/v1`. В документацию включены только пути `/api/v1/**`.

Для защищённых операций сначала вызовите `POST /api/v1/auth/login`, скопируйте поле токена из ответа и нажмите **Authorize** в Swagger UI. Введите значение в формате:

```text
Bearer <JWT>
```

После этого можно выполнять запросы к корзине, заказам, лицензиям и административным маршрутам. Для admin-операций токен должен принадлежать пользователю с ролью `ADMIN`.
